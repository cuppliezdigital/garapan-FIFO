🎯 1. Latar Belakang & Tujuan Sistem

Masalah di Lapangan Sebelum Ada Sistem:
  1. Risiko Aging / Overdue Paket: Paket mengendap lama tertimbun paket baru karena tidak ada kontrol FIFO ketat.
  2. Keterlambatan Penanganan Komplain: Masalah tertahan baru disadari setelah ada eskalasi komplain dari pelanggan.
  3. Pencatatan Manual Lambat & Human-Error: Update resi satu per satu butuh waktu lama dan rawan salah input digit.
  4. Tidak Ada Jejak Audit (Audit Trail): Sulit menelusuri penanggung jawab jika terjadi selisih data atau kehilangan fisik.
Solusi & Dampak yang Dihasilkan:
  • Deteksi Dini Paket Kritis: Sistem otomatis menghitung jam/hari mengendap dan memprioritaskan paket (>36j, >48j, >72j).
  • Efisiensi Kerja hingga 80%: Proses cek & update aksi paket selesai dalam hitungan detik via laser PDA Android.
  • Akuntabilitas Penuh: Setiap klik, scan, dan perubahan data tercatat dengan detail waktu, username, dan IP Address.

🚀 2. Daftar Fitur Lengkap & Fungsinya

A. Dashboard & Tabel Monitoring Utama

Fitur Fungsi Teknis & Operasional Manfaat Bisnis
Kartu Metrik Aging FIFO (Real-Time) Menghitung total paket aktif, prioritas kritis (>36 Jam), waspada (48-60 Jam), peringatan (48-72 Jam), dan overdue (>72 Jam). Memberikan *helicopter view* instan bagi supervisor untuk memantau kesehatan operasional gudang.
Quick Filter Tab (Prioritas Kritis vs Semua) 1-klik filter untuk memunculkan paket yang paling mendesak untuk segera diberangkatkan. Mencegah penalti SLA pengiriman dengan memprioritaskan barang terlama terlebih dahulu.
Pencarian Cepat Multi-Kolom Kolom pencarian responsif untuk mencari waybill, tanggal masuk, outlet tujuan, TLC, atau nama barang sekaligus. Operator menemukan data resi dalam hitungan milidetik tanpa perlu memuat ulang halaman.
TLC / GW Filter Combobox Dropdown pencarian pintar dengan autocomplete untuk menyaring paket berdasarkan kode gateway transit tertentu. Mempermudah penataan rute muat barang (*loading truck*) berdasarkan tujuan wilayah.
Sistem Multi-Checkbox & Bulk Action Bar Memilih puluhan hingga ratusan resi sekaligus untuk dieksekusi bersamaan (Update Aksi, Arsipkan, atau Hapus). Menghilangkan pekerjaan repetitif satu per satu sehingga menghemat waktu kerja berjam-jam.

B. Modul Barcode Scanner & Integrasi Hardware PDA

Fitur Fungsi Teknis & Operasional Manfaat Bisnis
Dual Operational Mode (Mode 1 vs Mode 2) Mode 1 (Cek FIFO): Cek umur paket, status, dan riwayat.
Mode 2 (Scan & Update Aksi): Sekali tembak laser, resi otomatis diupdate ke aksi yang dipilih.		 Fleksibilitas kerja untuk audit stok berkala maupun proses muat/sortir cepat.
Quick Action Chips (PDA Touch Jempol) Deretan tombol kapsul sentuh modern: ✓ Scan Kirim, ⏸ Penangguhan, ⚠️ Miss Route, 🏷️ Crosslabel, ✍️ Ketik Manual. Operator bisa mengganti target aksi hanya dengan 1 ketukan jempol tanpa membuka dropdown sempit di layar PDA.
Tombol Koreksi Instan ("Salah Aksi? Ubah Langsung") Baris tombol darurat di bawah kartu hasil scan: jika operator salah tembak aksi, cukup tap tombol aksi yang benar langsung di kartu. Mengoreksi kesalahan dalam 1 detik tanpa perlu scan ulang atau mencari resi manual di tabel.
Hardware Wedge & Auto-Burst Engine (160ms) Algoritma penangkap tembakan cepat laser PDA. Jika scanner tidak mengirim karakter Enter, timer 160ms otomatis mengeksekusi resi. Kompatibel dengan segala jenis merk PDA (Zebra, Honeywell, Chainway, Urovo) tanpa settingan rumit.
Global Window Wedge Buffer Sistem pendeteksi laser di level jendela browser. Jika kursor tidak sengaja lepas dari input, scanner tetap menangkap resi otomatis. Operator tidak frustrasi karena tembakan laser macet akibat layar tersentuh tidak sengaja.
Zero-Latency Web Audio Synthesizer Suara beeping murni Web Audio API Oscillator (Chime Sukses, Nada Peringatan 2 Tingkat, Buzzer Rendah Error). Zero-delay, hemat kuota, dan tetap berbunyi kencang di area gudang yang bising.
Haptic Vibration Feedback Menggetarkan bodi PDA Android saat laser menembak (getar pendek untuk sukses, getar ganda untuk peringatan/error). Operator mendapat konfirmasi fisik langsung di tangan tanpa harus selalu menatap layar.
Penanganan Resi Nyasar & Quick Add Modal Jika resi belum terdaftar, alarm buzzer berbunyi + tombol + Daftarkan Paket Ini Sekarang membuka pop-up input instan 5 detik. Mencegah paket misterius tertinggal di gudang tanpa data manifest yang jelas.
Drawer Riwayat Resi Nyasar Menyimpan daftar resi tidak terdaftar beserta waktu scan dan tombol Salin Semua ke Clipboard. Mempermudah rekonsiliasi paket nyasar ke tim investigasi atau admin kantor.
Kamera Scanner Fallback Menggunakan BarcodeDetector API kamera perangkat untuk membaca barcode jika operator tidak membawa mesin PDA fisik. Sistem tetap bisa digunakan di HP Android biasa jika perangkat PDA sedang di-charge atau terbatas.

C. Manajemen Data, Import, Export, & Arsip

Fitur Fungsi Teknis & Operasional Manfaat Bisnis
Import Massal Excel / CSV Upload file data monitoring harian dengan validasi otomatis per baris data via Multer. Memasukkan ribuan data resi baru dari sistem manifest pusat hanya dalam waktu beberapa detik.
Export Data ke Excel / CSV Download data monitoring aktif, riwayat, atau data terfilter ke file spreadsheet spreadsheet. Mempermudah pembuatan laporan berkala untuk dikirimkan ke manajemen pusat atau klien.
Sistem Arsip Mandiri (Archive & Restore) Memindahkan data paket yang sudah selesai/terkirim ke tabel arsip terpisah, dengan opsi mengembalikan jika diperlukan. Menjaga database tetap ringan dan cepat tanpa menghapus rekaman riwayat masa lalu.
Restore Status Update Fitur pembatalan status update resi untuk mengembalikan paket ke status awal (*Pending*). Menangani kasus pembatalan kirim secara aman tanpa merusak integritas data.

D. Keamanan, Pengguna, & Audit Trail

Fitur Fungsi Teknis & Operasional Manfaat Bisnis
Role-Based Access Control (RBAC) Pembagian peran terstruktur: Super Admin, Admin, Supervisor, Operator. Membatasi wewenang agar operator lapangan tidak bisa menghapus data atau mengotak-atik akun user.
Matrix Hak Akses Granular Pengaturan izin per fitur (Buka Scanner, Import Bulk, Edit Data, Hapus Data, Lihat Riwayat, Kelola User). Fleksibilitas konfigurasi izin sesuai SOP masing-masing cabang atau shift kerja.
Audit Trail Lengkap (Aktivitas User) Mencatat setiap aktivitas: waktu kejadian, nama user, role, aksi yang dilakukan, data lama vs data baru, IP Address, dan perangkat. Menjamin 100% transparansi. Jika ada data hilang atau salah ubah, penanggung jawabnya terlacak seketika.
Inactivity Session Auto-Logout Sesi login otomatis terkunci jika perangkat ditinggalkan tanpa aktivitas selama periode waktu tertentu. Mengamankan sistem dari penyalahgunaan saat PDA atau laptop ditinggal di meja gudang.
Kustomisasi Identitas Perusahaan Upload logo instansi (versi terang/gelap) dan kustomisasi background wallpaper secara dinamis. Memberikan sentuhan branding profesional resmi milik perusahaan.

🛡️ 3. Arsitektur Keamanan Sistem (Security Stack)

Sistem Monitoring FIFO dirancang dengan 7 lapisan keamanan standar perbankan dan industri enterprise:

Lapisan Keamanan Apa Itu? (Penjelasan Teknis) Kenapa Kita Pakai? (Alasan & Manfaat)
1. JWT Authentication Token digital bertanda tangan kriptografis dengan batas masa berlaku (*expiration time*). Bersifat *stateless* (tidak membebani database) dan kebal dari pemalsuan token atau pembajakan sesi login (*session hijacking*).
2. Bcrypt Password Hashing Enkripsi satu arah (*one-way salted hash*) berstandar perbankan internasional. Password tidak pernah disimpan dalam teks biasa. Dilengkapi salt acak unik per user sehingga kebal dari pencurian data & serangan *Rainbow Table*.
3. Parameterized Queries Semua query MySQL menggunakan Prepared Statements dengan placeholder tanda tanya (?). Perintah SQL dan data input dipisahkan secara tegas. Menjamin 100% kebal terhadap serangan berbahaya SQL Injection.
4. Helmet.js Headers Middleware keamanan yang menyematkan 11+ lapisan pelindung header HTTP pada Express. Mencegah serangan *Clickjacking* (X-Frame-Options), *MIME-sniffing*, dan menyembunyikan identitas mesin server dari peretas.
5. Strict CSP & No Inline Script Content Security Policy ketat; seluruh logika JS menggunakan Event Delegation tanpa inline onclick="...". Menolak segala bentuk eksekusi skrip jahat asing yang disuntikkan dari luar (Cross-Site Scripting / XSS).
6. Express Rate Limiting Pembatas frekuensi permintaan (*rate limiter*) pada endpoint login dan API sensitif. Memblokir bot yang mencoba menebak password ribuan kali per menit (*anti brute-force*) dan menjaga server tetap stabil dari serangan DDoS.
7. Granular RBAC System Validasi hak akses bertingkat di setiap pintu gerbang API backend (requirePermission & requireRole). Menerapkan prinsip militer *Least Privilege*. Divalidasi ganda di server sehingga tidak bisa dibobol lewat Postman (HTTP 403 Forbidden).
