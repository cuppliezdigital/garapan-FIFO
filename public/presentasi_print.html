1. Ringkasan Eksekutif & Latar Belakang

Sistem Monitoring FIFO Terintegrasi dibangun untuk menyelesaikan tantangan utama di operasional gudang logistik, yaitu penumpukan paket mengendap (stuck/aging), keterlambatan penanganan paket komplain, serta pencatatan manual yang rentan kesalahan manusia. Melalui kombinasi dashboard web real-time dan modul pemindai barcode laser pada perangkat Android PDA, sistem ini memastikan seluruh paket diproses dengan prinsip ketat First In, First Out (FIFO).

2. Katalog Fitur Operasional & Modul Scanner PDA

Nama Fitur Fungsi Teknis & Operasional Dampak & Manfaat Bisnis
Dual Mode Scanner (Cek FIFO & Update Aksi) Mode 1 (Cek): Memeriksa umur paket, gateway TLC, dan status tanpa merubah data.
Mode 2 (Update): Sekali tembak laser, resi otomatis diperbarui ke aksi target di database.		 Pekerjaan sortir dan pengelompokan muatan menjadi jauh lebih cepat dan teratur.
Quick Action Chips (PDA Touch Jempol) Deretan tombol kapsul sentuh modern: Scan Kirim, Penangguhan, Miss Route, Crosslabel, Ketik Manual. Cukup 1 sentuhan jempol untuk mengganti mode aksi. Operator tidak perlu repot membuka dropdown sempit di layar PDA Android.
Tombol Koreksi Instan ("Salah Aksi? Ubah Langsung") Tombol revisi cepat di bawah kartu hasil scan. Jika salah tembak aksi, operator langsung klik tombol tujuan di kartu tanpa perlu scan ulang. Mencegah human error tanpa membuang waktu membatalkan proses scan dari awal.
Hardware Wedge & Auto-Burst Engine (160ms) Mendukung tembakan cepat laser hardware PDA fisik. Jika scanner tidak mengirim karakter Enter, timer otomatis memproses resi begitu laser selesai nembak. Kompatibel dengan segala merk PDA (Zebra, Honeywell, Chainway, Urovo, dll).
Audio Synthesizer & Haptic Vibration Suara beeping zero-delay via Web Audio API (chime sukses, nada peringatan, buzzer merah) + getar fisik langsung di tangan operator. Operator mendapat konfirmasi seketika tanpa harus menatap layar terus menerus.
Penanganan Resi Nyasar (Quick Add Modal) Mendeteksi resi yang belum tercatat di database dengan alarm buzzer merah. Tombol + Daftarkan Paket Ini membuka pop-up input instan 5 detik. Mencegah paket misterius tertinggal di gudang tanpa data manifest yang jelas.
Import & Export Massal Excel / CSV Upload ribuan data resi baru dari file Excel/CSV pusat sekaligus men-download data terfilter untuk laporan harian. Integrasi manifest data harian dari pusat hanya butuh hitungan detik.
Sistem Arsip Mandiri (Archive & Restore) Memindahkan data paket lama/selesai ke tabel arsip terpisah agar database tetap cepat dan enteng. Performa aplikasi selalu responsif tanpa kehilangan riwayat lama.

3. Arsitektur Keamanan Sistem (Enterprise Security Stack)

Sistem Monitoring FIFO dibangun dengan prinsip Pertahanan Berlapis (Defense in Depth) untuk melindungi integritas data operasional dan mencegah sabotase data:

Lapisan Keamanan Teknologi yang Diterapkan Kenapa Dipakai? (Alasan & Manfaat)
Autentikasi Pengguna JSON Web Token (JWT) Token digital bertanda tangan kriptografis. Mencegah pemalsuan sesi login dan aman dari pembajakan akun (session hijacking).
Enkripsi Kata Sandi Bcrypt Hash + Salt Rounds Standar keamanan perbankan. Password tidak pernah disimpan dalam bentuk teks biasa. Kebal terhadap serangan pencurian data maupun Rainbow Table.
Proteksi Database Parameterized Queries (?) Semua query MySQL menggunakan Prepared Statements. Menjamin 100% kebal dari serangan SQL Injection (pencurian/penghapusan database melalui form input).
Proteksi Header Server Helmet.js Middleware Menyematkan 11+ pelindung HTTP: Anti-Clickjacking (X-Frame-Options), Anti-MIME Sniffing, dan menyembunyikan identitas software server dari hacker.
Proteksi Skrip Jahat Strict CSP & Event Delegation Menghilangkan semua inline onclick="...". Menolak segala jenis injeksi skrip asing dari luar (Cross-Site Scripting / XSS).
Proteksi Serangan DDoS Express Rate Limiting Membatasi percobaan login per IP address. Menghentikan bot yang mencoba menebak password dengan metode brute-force.
Manajemen Wewenang Granular RBAC System Pemisahan hak akses: Super Admin, Admin, Supervisor, Operator. Operator tidak memiliki akses untuk menghapus data atau menambah akun user lain.
Audit & Akuntabilitas Audit Trail Logging System Setiap perubahan data dicatat otomatis: nama user, waktu, IP address, nilai sebelum vs sesudah. Tidak ada perubahan yang bisa disembunyikan.
