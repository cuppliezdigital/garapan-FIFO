Alternatif: Panduan Ekstraksi Manual Auth Token JFS via Inspect (F12) Klik untuk buka / tutup
  1. Buka https://jfs.jtcargo.co.id di Chrome (posisi sudah login akun barcode).
  2. Tekan tombol F12 pada keyboard ➔ Buka Tab Network ➔ Pilih filter Fetch/XHR.
  3. Klik sembarang request di daftar lalu buka tab Headers.
  4. Cari tulisan authtoken: pada Request Headers, salin 32 karakter token tersebut.
  5. Paste ke form JFS Auth Token di atas lalu klik Simpan Pengaturan.
